# SiedliskoOS — Sprint 17: Smart Capture

## Zakres

- automatyczne rozpoznawanie portalu,
- odczyt tytułu, opisu, miejscowości, ceny i powierzchni z danych strony,
- wskaźnik pewności oraz lista pól do sprawdzenia,
- komunikat po zapisaniu nieruchomości,
- dashboard pokazujący najnowsze rekordy,
- bez zmian w istniejącej tabeli `properties` i bez tworzenia nowej bazy.

## Bezpieczna instalacja

Uruchom plik `ZAINSTALUJ_SPRINT_17.command` z Terminala. Instalator sprawdzi branch i czystość repozytorium, po czym scali pełną paczkę z projektem bez usuwania `.git`, bazy danych, `node_modules`, `dist` ani `target`.
