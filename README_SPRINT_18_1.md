# Sprint 18.1 — źródło ogłoszenia

Dodano bezpieczną migrację istniejącej tabeli `properties` o pola:
- `source_url`
- `portal`
- `listing_id`
- `captured_at`

Smart Capture zapisuje link i metadane źródła. Formularz nieruchomości pozwala je edytować oraz otworzyć oryginalne ogłoszenie. Istniejąca baza i rekordy pozostają bez zmian.
